## Medi Hospital Website

A modern, responsive hospital website built with React.js and CSS3 for Medi Hospital, Dhanbad.

The project focuses on creating a professional healthcare experience with clean layouts, smooth animations, responsive design, informative sections, and easy access to hospital services and contact information.

# Project Overview

Medi Hospital is a multi-page React website designed to present the hospital's:

- Healthcare services
- Hospital infrastructure
- Doctors and medical team
- Patient care facilities
- Events and activities
- Modern medical facilities
- Contact and enquiry information
- Hospital information and background

The interface is designed with a clean medical visual style using blue, cyan, white, and subtle neutral tones.

# Main Features

🏥 Hospital Website

- Professional hospital landing page
- Responsive navigation bar
- Hospital branding and logo
- Hero sections with healthcare-focused imagery
- Informative content sections
- Responsive footer

🩺 Services

- Dedicated services page
- Interactive service presentation
- Medical categories and specialties
- Modern visual layout
- Hover animations and responsive behavior

📸 Gallery

- The gallery page contains multiple sections:
- Hospital & Infrastructure
- Doctors & Medical Team
- Patient Care
- Events & Activities
- Modern Facilities

Gallery features include:

- Responsive masonry-style image grids
- Different image sizes for visual variation
- Image hover effects
- Title and description overlays
- Text truncation with ellipsis for small image cards
- Expand button for each image
- Full image lightbox
- Complete title and description inside the lightbox

📞 Contact
Hospital contact information

- Phone and email details
- Location information
- Working hours
Enquiry/contact form
- Quick communication actions

📱 Responsive Design

The website is designed for:

- Desktop
- Laptop
- Tablet
- Mobile devices

CSS media queries are used to adapt layouts, typography, spacing, navigation, galleries, and hero sections to different screen sizes.

✨ Animations

The project uses smooth animations for:

- Hero content
- Section appearance
- Image hover effects
- Gallery overlays
- Expand buttons
- Lightbox appearance
